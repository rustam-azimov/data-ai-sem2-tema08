## Как устроены тренажёры

SQL выполняется в браузере через [sql.js](https://github.com/sql-js/sql.js) 1.10.3 (SQLite в WebAssembly):
библиотека загружается с cdnjs, запасной адрес — jsdelivr, поэтому нужен интернет.
В тренажёре 08·2 таблицы доступны и как `students`, и как `grades.students` — запросы переносятся в DBeaver без правок.

Места для будущих видео размечены атрибутом `data-video-slot`: `t08-1-start`, `t08-2-start`, `lab08-dbeaver`,
`l08-schema`, `l08-having`, `l08-ai`.

Для встраивания в Moodle через `<iframe id="labframe">` тренажёры отправляют свою высоту сообщением
`postMessage` с типом `topic08_sql_review` (08·1) и `topic08_sql_queries` (08·2).
